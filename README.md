**Artificial Intelligence | Time Series Analysis | Machine Learning**

- Comparison of Logistic Regression, Random Forest, XGBoost, and SVM.

- Statistical significance testing and trading strategy simulation.
- Interactive application developed with Streamlit.

### 2. Food Packaging Purchase Prediction

**Machine Learning | Data Preprocessing | Predictive Analytics**

Development of predictive models to analyse purchasing behaviour based on survey data about food packaging preferences.

- Data cleaning and missing-value treatment.
- Categorical variable encoding and feature preparation.
- Logistic Regression modelling.
- Model evaluation using classification metrics.

### 3. Bank Fraud Detection

**Data Science | Machine Learning | Deep Learning**

Development and comparison of machine learning and deep learning models for detecting fraudulent banking transactions.

- Analysis of the Credit Card Fraud Detection dataset.
- Handling highly imbalanced classes.
- Comparison of Logistic Regression, Random Forest, XGBoost, and a neural network.
- Evaluation using precision, recall, and F1-score.
- Model interpretability and risk considerations.
